USCIS Case Tracker · Visual system

Quiet Instrument

A floating panel that reads like a well-made desktop tool, not a browser hack and not a government form. Shown here injected over a facsimile of my.uscis.gov, in light and dark, with fabricated case data.

The panel, in place

Three cases: an active I-485 with a full timeline and a change since last look, a closed I-765 that has been approved and the card mailed, and a sparse I-131 where the API returned almost nothing. Everything below the header scrolls; the header and footer do not.

Color — light

Accent is indigo and is reserved for interaction and "you have something new". Status is carried only by the four semantic hues. The two vocabularies never trade places, which is what keeps a dense panel readable. Ratios are measured against the surface each token is specified to sit on.

Color — dark

Dark is re-picked, not inverted: surfaces stay warm-neutral, borders lighten rather than darken, and every semantic hue is desaturated and lifted so nothing glows.

Type

System stack only. Six roles plus a micro size for chips. Tabular numerals everywhere a date or a receipt number appears, so columns of dates line up without a table.

Components

Every state is rendered, including :focus-visible, which is forced on with a helper class so it can be judged on paper.
